## 🚀 Projects

### 🤖 Fine-Tuning Phi-3 Mini — Programming Assistant

> Fine-tuned Microsoft's **Phi-3 Mini** (3.8B parameters) to create an AI that teaches programming with clean, well-structured and professional code.

- Created a **custom dataset** with 20 examples across 8 topics
- Applied **LoRA** — trained only **0.25%** of the model's parameters
- Used **4-bit quantization** to run on a free Google Colab GPU
- Loss dropped from **0.87 → 0.37** in 3 epochs
